# 情报输出标准
- 结构：**一句话结论 → 3–5 条要点（每条附来源链接）→ 对 OPC 的影响（机会/威胁/建议动作）→ 原始条目清单**
- 每条判断必须能追溯到 `items` 表里的 URL；找不到出处就写"未证实"，**禁止编造**
- 区分事实与观点：观点前加"判断："；数字写明口径和日期
- 去重：同一事件多源报道只算 1 条，列出全部来源
- 长度：日报 ≤ 600 字，周报 ≤ 1500 字；中文输出
- 质量自检（eval 会按这个打分）：结论是否可执行、引用覆盖率 = 100%、没有幻觉链接、没有重复条目
